# NepaliDirectory SEO baseline — 2026-08-03

This baseline separates observations supplied from live Google/production checks from measurements made against the release candidate. Values must be measured again after deployment; local build results are not production Core Web Vitals or Search Console data.

## Search context

- Target brand: `NepaliDirectory`; readable alternate: `Nepali Directory`.
- Primary query supplied by the site owner: `nepali directory`.
- Owner-observed position: approximately page 6 in a personalised Google result from Nepal, even for the business name.
- First-page competitors supplied by the owner included NepalYP, Yellow Pages Nepal, Directory Kathmandu, Directory of Nepal, Inquiry Nepal and B2BMAP.
- The name is both a new brand and a generic directory phrase. Google therefore needs consistent entity signals, useful inventory and external authority before it is likely to treat the query as navigational.

Rank positions vary by location, device, language, personalisation and date. The owner observation is a useful starting point, not a reproducible rank-tracker measurement.

## Pre-release technical observations

The earlier production audit recorded the following approximate raw HTML sizes:

| URL | Approximate HTML | Approximate cards | Risk |
|---|---:|---:|---|
| `/` | 167 KB | — | Acceptable |
| `/city/kathmandu` | 3.54 MB | 481 | Critical |
| `/city/lalitpur` | 2.22 MB | 295 | Critical |
| `/category/shops` | 3.28 MB | 416 | Critical |
| `/category/it-companies` | 1.70 MB | 209 | High |
| `/city/butwal` | 698 KB | 84 | High |

The earlier sitemap sample contained approximately 1,141 URLs: 30 static pages, 14 category/city URLs, 97 blog URLs and 1,000 business profiles.

Repository inspection also found:

- bundled demo businesses with unsupported rating, review-count, price, image and profile claims;
- no auditable verification/content-review state controlling every index-producing surface;
- all category and city cards rendered in a single response;
- fixture-backed `best`, `top-rated` and provider-comparison paths;
- build-derived or weak modification signals in sitemap paths;
- empty categories able to remain indexable;
- no crawlable, inventory-gated city/category route;
- JSON-LD serialized directly into script elements in multiple templates.

## Release-candidate measurements

Measured from `next start` after a successful production build with the bundled demo catalog deliberately ineligible:

| URL | Status | HTML bytes | Robots | Unsupported rating/price schema |
|---|---:|---:|---|---|
| `/` | 200 | 100,093 | `index, follow` | No |
| `/category/shops` | 200 | 71,048 | `noindex, follow` | No |
| `/city/kathmandu` | 200 | 96,295 | `noindex, follow` | No |
| `/business/newa-lahana` | 200 | 53,190 | `noindex, follow` | No |
| `/best-businesses` | 200 | 65,579 | `noindex, follow` | No |
| `/compare-business` | 200 | 144,737 | `index, follow` | No |

Additional results:

- `/top-rated` permanently redirects to `/best-businesses`.
- The empty demo inventory produces no listing sitemap chunk.
- `/sitemap-categories.xml` contains no category/city URL without ten qualifying profiles.
- `/sitemap-listings-1.xml` returns 404 when there are zero qualifying profiles.
- `/city/kathmandu/restaurants` returns 404 below the inventory threshold.
- Tested pages contain no `<meta name="keywords">` output.
- Result pages contain compact ItemList objects rather than full LocalBusiness graphs.

## External measurements still required

These values require production or owner account access and were not fabricated:

- Google Search Console manual actions/security status;
- submitted, discovered, crawled and indexed URL counts;
- URL Inspection results for the homepage and representative templates;
- query impressions, clicks, CTR and average positions;
- field Core Web Vitals by template;
- backlink/referring-domain distribution and competitor link gaps;
- real counts by verification status after migrations and review;
- current production release identifier and database-backup identifier.
